Show pointer¶

The show-pointer kitten shows what a terminal reports to programs for the input devices that are more than a mouse: the pens and pads of graphics tablets, touchscreens, touchpads, the gestures made on them and scrolling. It speaks the tablet pointer, gesture and scroll protocols, which are open terminal extensions framed as OSC 777. Run it in the terminal you want to know about:

kitten show-pointer

It first asks the terminal which of the protocols it speaks and what it can report with each, and says so in words. Then it turns on every kind of report the terminal offers and prints one line for each report it receives, until you press Ctrl+C, Ctrl+D or q:

tablet tool down device=3 contact=0 tool=pen x=100.00px y=200.00px cell=8,8 buttons=tip mods=none valid=pressure+tilt pressure=0.488 tilt=-12.00°,6.00° t=408211ms
tablet tool move device=3 contact=0 tool=pen x=101.00px y=200.00px cell=8,8 buttons=tip mods=none valid=pressure+tilt pressure=0.502 tilt=-12.00°,6.00° t=408215ms dt=4ms
gesture pinch update x=100.00px y=200.00px cell=8,8 mods=none scale=+12.0% total=x1.340 t=408230ms dt=8ms
scroll precise moving dx=+0.00px dy=+2.50px x=33.00px y=12.00px cell=2,0 mods=shift t=408244ms dt=8ms

Values are converted to the units a person reads: positions in pixels and as the zero based column and row of the cell they fall in, pressure as a fraction of the full range, angles in degrees. dt is the time since the previous report of the same contact, which is how to see the rate a device reports at. A field or a kind of report the kitten has no name for is printed as the terminal sent it, never dropped, so a terminal that implements a later version of a protocol can still be examined.

While the kitten runs, a pen or a finger over its window is reported to it instead of acting as a mouse, and with scroll reports on the terminal does not scroll its scrollback. To watch only some of the sources, name them:

kitten show-pointer --only tools,pads

A system that judges whether a contact is meant, or is an accident such as a palm, has its judgement shown with each finger as conf=meant or conf=accidental. A finger the system has said nothing of has neither, which is every finger on a system that does not judge. A terminal keeps the accidental contacts from a program that does not ask for them, and the kitten asks a terminal that says it has them, so it shows them all. Leave accidental out of --only to see what a program that does not ask is shown instead: a contact that comes to be taken for an accident is cancelled, and begins again when it no longer is.

On exit, and while it is stopped with Ctrl+Z, the kitten turns off everything it turned on. In a terminal that speaks none of the protocols it says so and exits with a non-zero status, which makes it usable as a test in a script.

Reporting a problem¶

To send someone what your terminal reports for your tablet, use --raw, which prints the frames exactly as the terminal sent them, and redirect the output to a file:

kitten show-pointer --raw > report.txt

The terminal you run this in is still the one that is examined, only the output goes to the file. Move the pen, press its buttons and the keys of the tablet, then quit and attach the file. Lines starting with # are the kitten’s own description of the terminal.

The serial number of a pen identifies the pen and so its owner. Unless --ids is given, the kitten does not ask the terminal for hardware identifiers, and replaces a serial number the terminal sends regardless with a counter, #1 for the first pen seen, #2 for the second, which is enough to tell two pens apart.

Command line options¶

--only <sources>¶

Enable only the named sources, separated by commas. This option may be repeated. Sources are tools, fingers, pads, actions, estimates, accidental, gestures, hold, and scroll. tablet-pointer and gesture each select all sources of that protocol. By default, all sources the terminal offers are enabled.

--ids¶

Request hardware identifiers and show them. Without this option, identifiers are not requested and any pen serial numbers received are replaced by counters.

--raw¶

Print the received frames without decoding them, one per line. Other output lines begin with #.

--timeout <seconds>¶

Wait this long for each round of queries. The default is 2 seconds.
