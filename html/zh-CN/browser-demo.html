Silkie / 终端模拟器 / macOS + Linux

在浏览器中试用 Silkie¶

真正的 Linux shell，就在当前标签页中本地运行。试试基本命令，玩 Presidential、Silkie Loophole、Sprint 和 Scramble，或者通过 SSH 连接自己的机器。终端会自动启动。

点击终端即可输入，拖动选择文本后可照常复制。使用 全屏 获得更多空间和稍大的字体。终端下方的游戏链接会在独立窗口中打开游戏，窗口内即可开始游玩。在游戏窗口中使用 全屏 还可隐藏浏览器控件。

安装 Silkie 以使用原生终端，或浏览 扩展参考手册。

silkie_

正在启动 shell…

在独立终端窗口中游玩： Presidential · Silkie Loophole · Silkie Sprint · Silkie Scramble. 使用全屏占满显示器。 SSH 设置 · 由 CheerpX 提供支持

试试这些命令¶

ls
printf 'Hello from Silkie!\n'
silkie-features
silkie-sprint
silkie-scramble
presidential
silkie-loophole

点击终端即可输入。Sprint 和 Scramble 使用方向键或 WASD 操作；按 P 暂停，再按 Q 退出。Loophole 使用方向键或 WASD 行走，空格键交互，? 查看帮助。Presidential 启动后显示竞选菜单；使用 F1–F9 浏览各面板，? 查看帮助。首页的 shell 与各游戏窗口可同时运行，文件和存档分别保存在浏览器的本地存储中。再次点击同一游戏链接会返回已有窗口。每款游戏只保留一个窗口，以保护其文件系统。浏览器的存储配额仍然适用。silkie-features 会按当前终端宽度排版报告，调整大小或切换全屏后也会适配。

连接自己的机器¶

在终端中选择 连接 Tailscale，点击登录链接，加入自己的网络。然后在 shell 中运行 ssh your-user@your-tailscale-address。页面会显示虚拟机的连接状态和地址。目标机器需要运行 SSH 服务，并允许你访问。

Silkie 不提供公共中继。可以在自己的 Tailscale 机器上使用 Ncat，将连接转发到局域网内的 SSH 服务器。设置方法、命令和主机密钥验证见 浏览器演示中的 SSH。

Linux 执行环境由 Leaning Technologies 的 CheerpX 提供，按社区许可从其托管运行时加载。Silkie 基于 kitty 开发。请参阅 Silkie 扩展参考手册和上游协议手册。kitty 的配套工具和插件称为 kittens。浏览源代码。
