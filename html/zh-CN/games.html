Silkie 与 kitty 游戏¶

在网站的 Linux 终端中试玩全部五款游戏，或在原生 Silkie 和 kitty 终端中运行。每个浏览器链接都会在独立窗口中打开终端，并自动启动游戏。使用 全屏 隐藏浏览器控件。各游戏的文件和存档分别保存在浏览器本地存储中；再次打开链接会返回已有窗口。

  • 全屏游玩 Silkie Loophole
  • 全屏游玩 Ground Stop

Presidential¶

你是美国总统。在全球经济模拟中阅读每日简报、起草命令，再按 GO 推进一天。探索贸易、金融、政府、外交以及政策的影响。用 F1–F9 切换面板，B 查看简报，? 查看帮助。竞选进度会在每天结束后和退出时保存。

在 presidential 检出目录中运行 cargo install --path crates/terminal-ui 构建，再运行 presidential。经济数据和世界地图已内嵌，游戏可离线运行。参阅 Presidential 源码。

Silkie Loophole¶

一只披着床单的浣熊，在佛蒙特州蒙彼利埃四处讨糖。收集糖果、发现邻居们的作息，并努力维持伪装。方向键或 WASD 行走，空格或 Enter 交互，M 打开地图，J 查看日记，? 查看帮助，Ctrl+C 退出。

按下文“安装 Sprint 和 Scramble”配置软件仓库后安装：运行 macOS 26 Tahoe 的 Apple Silicon 机器使用 brew install goblinreactor/tap/silkie-loophole，Ubuntu 26.04 amd64 或麒麟 V10 SP1 旧世界 LoongArch64 使用 sudo apt-get install silkie-loophole。然后运行 silkie-loophole。参阅 Loophole 源码与手册。

Ground Stop¶

美国最后一座机场在佛蒙特州蒙彼利埃。

一次软件更新让美国所有机场停摆，只有仍在使用软盘的蒙彼利埃市立机场幸免，这一地区的所有飞机都在朝它飞来。在扫描雷达上引导它们降落，这是一款没有尽头的空中交通管制游戏。每架飞机都有真实的飞行模型，包括阻力、发动机、燃油、结冰和风。

点击飞机将其选中。W 和 S 设定速度，A 和 D 设定航向，Z 和 X 设定高度。按 Enter 接受它提供的着陆方案，或点击跑道、道路或田野，让它在那里降落。Tab 选择下一架飞机，空格键暂停，? 显示帮助。连按两次 Q 退出。

在 ground-stop 检出目录中运行 cargo install --path . 构建，再运行 ground-stop。Silkie 以保留式矢量图形绘制雷达；普通 kitty 则以像素接收同样的雷达画面。参阅 Ground Stop 源码与手册。

Sprint 与 Scramble¶

Silkie Sprint 和 Silkie Scramble 是发生在同一后院世界的街机游戏，每段冒险都以一只丝羽乌骨鸡为主角。两款游戏在终端中运行，需要终端支持图形协议。下面的视频展示了在 Silkie 中游玩的实际画面。

两款游戏均支持 kitty，并为 Silkie 做了优化。在两个终端中，规则、计分和难度相同；Silkie 的扩展改善图形、输入和时序。安装 Silkie 的方法见 安装 Silkie。

安装 Sprint 和 Scramble¶

运行 macOS 26 Tahoe 的 Apple Silicon 机器可使用 Homebrew 仓库：:

brew tap goblinreactor/tap https://brew.goblinreactor.com/homebrew-tap.git
brew install goblinreactor/tap/silkie-sprint goblinreactor/tap/silkie-scramble

在 Ubuntu 26.04 amd64 或麒麟 V10 SP1 旧世界 LoongArch64 上，为系统配置 已签名 APT 仓库：Ubuntu 使用 resolute，麒麟使用 kylin。然后安装：:

sudo apt-get update
sudo apt-get install silkie-sprint silkie-scramble

打开 Silkie 或 kitty，运行 silkie-sprint 或 silkie-scramble。游戏和终端是独立的软件包。当前可用平台请查看仓库的软件包列表。麒麟软件包使用旧世界 loongarch64 ABI，与新世界 loong64 不同。

Silkie Sprint¶

跳过车流，搭乘漂木，必要时展翅飞翔。

引导一只丝羽乌骨鸡穿过道路、铁路和河流，抵达鸡舍。躲开车流，搭乘漂浮的木头，跳入空巢产蛋。填满所有巢位，蛋便会孵化。母鸡能短暂飞行，但翅膀需要在地面恢复，天空中也有危险。

方向键或 WASD 跳跃，空格起飞或落地，P 暂停。

Silkie Scramble¶

召集小鸡，提防狐狸，带它们回家。

探索花园迷宫，召集四处游荡的小鸡，带它们返回鸡舍。狐狸、黄鼠狼和鹰威胁着鸡群。一次带回更多小鸡能获得更高分数，但队伍越长，保护起来也越困难。绘制临时围栏引开捕食者，并利用花园门控制它们的路线。

方向键或 WASD 移动。用鼠标绘制围栏；在 Silkie 中也可使用笔或触摸屏。空格放置障碍，或操作附近已上闩的门。P 暂停。

Silkie 带来的增强¶

两款游戏都会在启动时探测终端能力，并使用 kitty 的 图形协议 显示精灵。Silkie 的扩展协议提供：

  • 保留式矢量场景，通过小型场景补丁更新巢位内容、门和围栏等变化。

  • 游玩时使用 画面呈现反馈 与 低延迟模式。

  • 在支持的显示器上使用 广色域 和 HDR 高光，以及 半透明菜单。

  • 在支持的平台上使用 笔与触摸屏输入、触觉反馈 和 自定义指针图像。

  • Scramble 中通过 终端侧墨迹 用笔绘制围栏。

运行游戏时加上 --kitty-only，可比较基础画面与 Silkie 增强效果；加上 --report 可查看探测到的能力。请直接在终端中运行；游戏不会为 tmux 或 screen 配置图形透传。
