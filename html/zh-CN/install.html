安装 Silkie¶

Silkie 从本仓库的 silkie 分支 构建。安装后的可执行文件为 silkie，配套工具使用 silkie-kitten。上游 kitty 软件包提供上游 kitty，不包含 Silkie 的扩展。

二进制软件包¶

在支持的 macOS、Ubuntu、Debian 或麒麟系统上安装 Silkie 和 Iosevka：:

curl -fsSL https://silkie.goblinreactor.com/install.sh | bash

安装脚本会说明所需的 Goblin Reactor 软件源，并在添加或修改之前征求许可。它会复用匹配的现有软件源，验证 APT 签名密钥，并通过 Homebrew 或 APT 安装 silkie。此外还会安装未经修改的 Iosevka 字体：macOS 使用官方 Homebrew font-iosevka cask，Linux 则下载并校验上游发布文件的校验和。软件源许可从终端读取，因此脚本通过管道传给 Bash 时也能使用。macOS 需要 Apple Silicon 和 macOS 26 或更高版本；如果缺少 Homebrew，脚本会征得许可后安装。

macOS 应用没有使用 Apple Developer ID 签名，也未经公证，因此安装脚本和 Homebrew cask 会在安装后清除它的隔离标记；否则 macOS 会拒绝打开它。

手动安装命令如下。

在运行 macOS 26 Tahoe 的 Apple Silicon 机器上，安装 Homebrew cask：:

brew tap goblinreactor/tap https://brew.goblinreactor.com/homebrew-tap.git
brew install --cask goblinreactor/tap/silkie
brew install --cask font-iosevka

cask 会在安装后清除应用的隔离标记。如果 macOS 仍然阻止首次启动，请在“系统设置 > 隐私与安全性”中批准 Silkie，或运行 xattr -dr com.apple.quarantine /Applications/silkie.app。Homebrew 仓库的 Silkie 安装说明 介绍了批准步骤和可用版本。

Linux 的 已签名 APT 仓库 提供安装说明、签名密钥和各发行版的软件源配置。当前目标包括 Ubuntu 26.04 的 amd64 和 arm64，以及旧世界 LoongArch64（loongarch64）的麒麟 V10 SP1。仓库还列出了 Ubuntu 24.04 和 Debian 13 的 amd64 软件包。请选择与系统匹配的发行套件；旧世界 loongarch64 和新世界 loong64 是不同的二进制目标。

按上述说明配置软件源后：:

sudo apt-get update
sudo apt-get install silkie

运行 silkie 启动终端，使用 silkie-kitten 运行配套工具。

检查已安装的命令：:

silkie --version
silkie-kitten --version
silkie-kitten show-pointer --help

2026 年 10 月 28 日，已检查上述五个目标的 Linux 仓库签名、软件包校验和以及可执行文件链接。还在 Ubuntu 26.04 amd64（naamah）和麒麟 V10 SP1 LoongArch64（loongson）上测试了 APT 安装与原生模块加载。

Silkie Sprint 和 Silkie Scramble 游戏 以独立的 Homebrew 和 APT 软件包分发。游戏页面包含安装命令、支持的平台、操作方法和实机视频。

字体¶

安装脚本包含 Silkie 默认文本使用的 Iosevka 字体；常规、粗体和斜体均使用较宽的 Extended 字形。手动安装时，macOS 可使用 brew install --cask font-iosevka；Linux 可从 Iosevka 发布页 下载未经修改的字体。Linux 安装脚本目前固定使用 Iosevka 34.9.1。

Iosevka 的版权属于 Renzhi Li，按 SIL 开源字体许可证 1.1 分发。该许可证允许使用、安装和随软件一起分发字体，前提是保留许可证与版权声明；字体不得单独出售。安装脚本下载原始字体，不修改或重命名字体，并将对应的 Iosevka-LICENSE.md 保存到字体文件旁。字体与 Silkie 采用各自独立的许可证。

如需使用 Iosevka 原来较窄的字宽，可配置：:

font_family Iosevka
font_role sans Iosevka

衬线字体角色需要另行安装 Iosevka Slab。中日韩文本可安装相应地区的 Sarasa Term 或 Noto Sans CJK 字体。字体文件与应用分开提供；首选字体缺失时，操作系统会替换为可用字体。字体选择协议 列出了字体来源，并说明了地区字形的选择方式。

从源码构建¶

前置依赖¶

安装 Git、C 编译器和 Go。Go 的最低版本在 silkie 分支的 go.mod 中声明。

在 macOS 上，若尚未安装 Apple 命令行开发工具，请运行 xcode-select --install。在 Linux 上，安装 kitty 构建前置条件 列出的 X11 和 D-Bus 开发库。

dev.sh 使用支持平台的预构建依赖，包括 Python 环境。首次构建需要联网下载这些依赖。构建实现 位于本仓库中。若要使用系统库构建，请参阅 上游依赖列表；macOS 还可参阅 Silkie 的 Brewfile。

构建与启动¶

macOS 的依赖配置使用相对于加载器的库引用，避免检出路径超出已下载库的 Mach-O 加载命令空间。如果上次下载或重定位不完整，会自动重试配置。2026 年 10 月 28 日，包含此修复的全新检出版本已通过构建和原生模块加载检查。

git clone --branch silkie https://github.com/adamdeprince/silkie.git
cd silkie
./dev.sh build
./kitty/launcher/kitty

运行开发构建时，请保留检出目录。修改源码后重新运行 ./dev.sh build。开发构建使用内部路径 kitty/launcher/kitty 和 kitty/launcher/kitten，而不是安装后的 silkie 与 silkie-kitten 命令。在 macOS 上，构建还提供 kitty/launcher/kitty.app；未签名应用和移动检出目录的说明见 上游构建文档。

试用输入检查工具¶

在已安装的 Silkie 终端中运行：:

silkie-kitten show-pointer

源码构建请在仓库目录中运行工具。macOS：:

./kitty/launcher/kitty.app/Contents/MacOS/kitten show-pointer

Linux：:

./kitty/launcher/kitten show-pointer

show_pointer 工具 会查询输入协议，并显示终端和已连接设备支持的事件。
