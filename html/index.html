Silkie / Terminal emulator / macOS + Linux

A terminal for richer interaction.¶

Silkie is a terminal emulator for macOS and Linux, built on kitty. It extends the terminal with pen and touch input, vector graphics, HDR color, and display timing feedback.

Run your shell and terminal applications. Build software that can draw, respond to a stylus, and understand the display it is running on.

Features¶

Silkie adds protocols that applications can discover and use as needed. Support depends on the operating system, input device, display, and compositor; each specification describes its capabilities and limits.

Fonts and typography¶

Mix Iosevka’s sans-serif and slab-serif faces, select weights from Thin to Heavy, and control slant in either direction. Regional CJK font preferences preserve character widths and the terminal grid. Font files are installed separately; see Font selection protocol for configuration and escape sequences.

Pen, touch, and gestures¶

Give applications pressure and tilt information, touch contacts, smooth scrolling, and gesture events. Inspect what a device reports with the show_pointer kitten.

Tablet input · Scrolling · Gestures · Haptics

Vector graphics and ink¶

Send paths, styled text and scenes for the terminal to render at the displayed size, with session fonts, text measurement, nested window clips and HDR color. Let the terminal draw pen strokes as input arrives, without waiting for each sample to make a round trip to the application.

Vector images · Terminal-side ink · GPU surfaces

Color beyond ordinary SDR¶

Use wider color spaces and request brightness above SDR white on supported displays. Query the available headroom and control transparency at the cell level.

HDR · Wide gamut · Cell alpha

Display and presentation feedback¶

Learn about the display, receive input timing information, and track when a frame is presented. Use those reports to coordinate drawing with the terminal.

Display information · Latency · Frame presentation

Install¶

Binary packages are available from Homebrew for Apple Silicon macOS, and the APT repository for Linux. See Install Silkie for the supported targets and installation instructions.

To build from source, use the silkie branch. You will need Git, a C compiler, and Go; Linux also needs the system libraries listed in the installation guide. The build script downloads the remaining build dependencies.

git clone --branch silkie https://github.com/adamdeprince/silkie.git
cd silkie
./dev.sh build
./kitty/launcher/kitty

The executable retains the name kitty. Running this checkout’s executable launches Silkie with its extensions. Upstream kitty packages install upstream kitty; use the Silkie packages or source above to get these additions.
