Accessibility¶

Magnify a pane¶

Use View → Magnify Pane, or press Ctrl+Alt+= to zoom in, Ctrl+Alt+− to zoom out, and Ctrl+Alt+0 to return to actual size. Ctrl+Alt+Arrow pans a magnified pane and Ctrl+Alt+C centers it on the text cursor. On a touchscreen that delivers direct touch events, spread two fingers to zoom and move both fingers together to pan. When a pane is already magnified, a trackpad pinch zooms around the pointer.

Magnification preserves the program’s rows, columns, and text layout. Silkie rerasterizes glyphs and vector graphics at the requested resolution, subject to renderer and hardware limits.

By default, once a raster image becomes visible during zoom, Silkie reports pixel dimensions at the next whole-number scale, capped at three times the base size. It reports 2× for zoom above 1× through 2×, and 3× above 2×. At actual size it reports the base resolution. Silkie updates the PTY pixel dimensions when the reported scale changes, which delivers a SIGWINCH on systems that signal pixel-size changes, and sends an in-band resize report to applications that enabled one. A program can query the reported cell size with CSI 16 t and send an image at that pixel density while keeping the same placement in cells. Silkie scales the available image locally to the selected zoom level.

To save bandwidth, keep the reported pixel dimensions at their base values by setting magnify_raster_resolution in silkie.conf:

magnify_raster_resolution no

Bind magnify_pane in silkie.conf to customize the controls. A numeric argument sets the magnification. Optional one-based row and column arguments set the center in the visible terminal grid. For example:

map kitty_mod+f11 magnify_pane 3 12 40
map kitty_mod+f12 magnify_pane reset

Silkie also samples desktop zoom on its existing display-monitoring wakeup. It reads GNOME Zoom’s settings, queries KWin versions that report the target zoom, and checks whether macOS Accessibility Zoom is active. The macOS zoom factor is available on a best-effort basis. With desktop zoom, final sharpness depends on how the compositor scales the window. Android tablets running Silkie in an X11 or Wayland session can use the pane magnifier. The Android system magnifier belongs to the Android host and its factor is available to Android accessibility services.

Review terminal images¶

Choose View → Review Images or press kitty_mod+alt+i to read the images in the active pane’s viewport. The review uses a selectable, read-only text view on macOS or with the Linux GTK backend. When the native backend is unavailable, Silkie uses the configured scrollback pager. Close the review to return keyboard focus to the pane.

The review lists images from top to bottom and left to right. It includes essential, informative, and unclassified images. Each entry identifies its purpose and location and includes the name, description, and details the program supplied. To include decorative images, choose Review All Images. Scroll the pane first to review images further back in its output.

Both actions can be bound in silkie.conf:

map kitty_mod+alt+i review_images
map kitty_mod+alt+o review_all_images

Describe image placements¶

Any program using the kitty graphics protocol can annotate a placement. This works with raster graphics and Vector images, including SVG. Give the image and its placement nonzero i and p IDs and send the annotation after placing the image.

Discover support by sending the Extension capabilities protocol query and looking for a11y.1 in ext. The selector uses OSC 777 extension framing.

<OSC> 777 ; a11y ; v=1 : op=set-image : i=17 : p=3 : purpose=essential : name=Latency%20by%20request%20rate <ST>

set-image replaces the annotation as a unit. clear-image takes the same placement IDs and removes the annotation. Omitting a descriptive field in set-image clears its previous value.

Field

Value

i

Image ID, required. An unsigned 32-bit integer greater than zero.

p

Placement ID, required. An unsigned 32-bit integer greater than zero.

purpose

essential for an image that carries the subject or result, informative for supporting material, or decorative for visual ornament. Omit the field to leave the purpose unclassified.

name

Optional short, single-line name.

description

Optional summary of what the image communicates.

details

Optional longer plain-text explanation, data table, or reference URL. The review presents URLs as text that the user can copy.

id

Optional reply correlation ID from zero to 2147483647.

Percent-encode the UTF-8 bytes of all three text fields, especially colons, percent signs, and non-ASCII bytes. Percent escapes take two hexadecimal digits. Invalid escapes, invalid UTF-8, and control characters reject the entire update. A description or details may include tabs and line breaks encoded as %09 and %0A.

When the request includes id, a successful update replies with OK. A missing image or placement replies with ENOENT. An allocation failure can reply with ENOMEM. Malformed requests receive no reply.

<OSC> 777 ; a11y ; v=1 : op=ack : id=42 : status=OK <ST>
<OSC> 777 ; a11y ; v=1 : op=clear-image : i=17 : p=3 : id=43 <ST>

An annotation belongs to the active screen and follows its placement into scrollback. Moving an existing placement keeps the annotation. Deleting a placement or replacing the image data removes it along with the placement. Virtual placements describe the visible runs of their Unicode placeholders. The review shows one entry per visible virtual placement.

SVG example¶

This Python program places a small SVG plot and describes its result. Its standard output should go to a Silkie terminal with SVG and image annotation support:

from base64 import b64encode
from urllib.parse import quote

svg = (
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 120 48">'
    '<path d="M4 42 H116 M4 42 V4" stroke="#879581"/>'
    '<path d="M4 34 L78 33 L112 7" fill="none" stroke="#77bb42" stroke-width="3"/>'
    '</svg>'
)
print(f'\x1b_Ga=T,f=201,i=17,p=3;{b64encode(svg.encode()).decode()}\x1b\\', end='')
name = quote('Latency by request rate', safe='')
summary = quote('Latency stays below 20 ms through 800 requests per second, then rises sharply.', safe='')
print(f'\x1b]777;a11y;v=1:op=set-image:i=17:p=3:purpose=essential:name={name}:description={summary}\x1b\\', end='', flush=True)

The application supplies the descriptions in the review. A future on-demand interpretation action could use the placement ID to identify the image the user selects.
